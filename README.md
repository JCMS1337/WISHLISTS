# Вишлисты (Wishlist site)

Простейший одностраничный сайт, где пользователи могут добавлять свои вишлисты. Данные отправляются в Firebase Realtime Database через REST API.

Главные файлы:
- `index.html` — интерфейс и форма добавления (кнопка `ДОБАВИТЬ`).
- `app.js` — логика: отправка и получение данных через полученный URL Realtime Database.
- `styles.css` — простые стили.

Конфигурация базы данных использует URL:

`https://wishlists-web-default-rtdb.europe-west1.firebasedatabase.app`

Запуск локально (PowerShell):

```powershell
# перейти в папку проекта
cd 'C:\Users\Admin\Desktop\wishlist'

# Запустить простой HTTP-сервер (если установлен Python)
python -m http.server 8000

# Открыть браузер и перейти на http://localhost:8000
```

Примечания:
- Этот проект использует REST-запросы к Realtime Database (`/wishlists.json`). Убедитесь, что правила базы данных позволяют запись/чтение с клиента (или настроите аутентификацию).
- Если база требует авторизации, нужно добавить токен или использовать официальную Firebase SDK и конфигурацию проекта.

Дополнительно (реализовано):
- Удаление: в списке у каждого вишлиста есть кнопка `Удалить` (HTTP DELETE к `/wishlists/{id}.json`).
- Редактирование: кнопка `Изменить` открывает форму редактирования (PATCH к `/wishlists/{id}.json`).
- Хеширование: перед отправкой создаётся SHA-256 хеш содержимого вишлиста и сохраняется в поле `hash`. Это помогает проверять целостность/идентичность на стороне клиента.
