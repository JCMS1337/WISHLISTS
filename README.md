# Вишлисты (Wishlist Site)

Полнофункциональный одностраничный сайт вишлистов с авторизацией, профилями пользователей и расширенной кастомизацией.

## Главные возможности

### Авторизация и профиль
- **Единая страница авторизации** (`auth.html`) — переключение между входом и регистрацией
  - **Регистрация** — создание аккаунта с никнеймом, email и паролем
  - **Вход** — аутентификация через Firebase
- **Профиль** (`profile.html`) — страница пользователя с:
  - Никнеймом и аватаром (первая буква ника)
  - Описанием о пользователе (поле «Об этом вишлисте»)
  - Управлением собственными вишлистами

### Вишлисты
- **Создание** — название, описание, категория, список товаров
- **Редактирование** — изменение любых параметров
- **Удаление** — с подтверждением
- **Категории**: Общее, Технология, Книги, Игры, Спорт, Искусство, Другое

### Главная страница
- **Список всех вишлистов** — публичное отображение вишлистов других пользователей
- **Фильтры** — по категориям
- **Поиск** — по никнейму пользователя
- **SHA-256 хеш** — каждый вишлист подписан хешем для проверки целостности

## База данных (Firebase Realtime Database)

### Структура данных

```
wishlists/
  {userId}/
    {listId}/
      - title: "Название вишлиста"
      - description: "Описание"
      - category: "tech|books|..."
      - items: ["Товар 1", "Товар 2", ...]
      - timestamp: 1702000000000
      - hash: "sha256hash..."

users/
  {userId}/
    - username: "nikname"
    - email: "user@mail.com"
    - bio: "Об этом пользователе"
    - avatar: "" (зарезервировано)
    - createdAt: 1702000000000
```

URL базы данных: `https://wishlists-web-default-rtdb.europe-west1.firebasedatabase.app`

## Запуск локально

### Требования
- Python 3.x (для локального сервера)
- Современный браузер с поддержкой ES modules и Web Crypto API
- Доступ в интернет (для Firebase Realtime Database)

### Шаги

1. **Скачать и распаковать проект** в папку `c:\Users\Admin\Desktop\wishlist`

2. **Запустить локальный сервер** (PowerShell):
   ```powershell
   cd 'C:\Users\Admin\Desktop\wishlist'
   python -m http.server 8000
   ```

3. **Открыть в браузере**: http://localhost:8000

4. **Первый запуск**:
   - Попадёшь на страницу авторизации (`/auth.html`)
   - Выбери режим **Регистрация** (или остаётся на **Входе** по умолчанию)
   - Для регистрации: введи никнейм, email, пароль
   - После входа: попадёшь в профиль (`/profile.html`)
   - В профиле можно создать вишлист
   - На главной странице (`/index.html`) видны вишлисты всех пользователей

## Использование

### Авторизация
- Перейти на `/auth.html`
- Выбрать режим: **Вход** или **Регистрация**
- **Для входа**: ввести email и пароль
- **Для регистрации**: ввести никнейм, email, пароль (двойной ввод для подтверждения)
- Нажать соответствующую кнопку

### Создание вишлиста
- После входа перейти в профиль (`/profile.html`)
- Заполнить форму: название, описание, категория, товары
- Нажать «Добавить/Обновить вишлист»

### Просмотр других вишлистов
- На главной странице (`/index.html`) отображаются все публичные вишлисты
- Использовать фильтры по категориям
- Искать по никнейму пользователя

## Безопасность

- Все данные передаются по HTTPS при обращении к Firebase Realtime Database
- **Пароли хешируются SHA-256** перед сохранением в БД
- Правила БД разрешают публичное чтение и запись (для демо) — в продакшене нужно ограничить
- **Каждый вишлист подписан SHA-256 хешем** для проверки целостности
- Текущий пользователь хранится в localStorage (для сеанса)

⚠️ **Важно для продакшена:**
Измени правила доступа на:
```json
{
  "rules": {
    "users": {
      "$uid": {
        ".read": "root.child($uid).exists()",
        ".write": "$uid === auth.uid"
      }
    }
  }
}
```
